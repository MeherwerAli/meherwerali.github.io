# Two-to-three-minute demo script

1. Open with the positioning statement and the three-system thesis.
2. Walk one flagship dossier from problem through architecture, failure semantics, security boundary, evidence, decisions, and limitations.
3. Show the local-evidence/publication-gate label and explain why missing releases or GPU metrics are not implied.
4. Resize to a 390 px viewport and show the single-column case studies without horizontal overflow.
5. Open one verified supporting repository link.
6. Close with the engineering posture: deterministic tests, runtime integration, and benchmarks are different evidence classes.

The public recording remains gated until its target repositories and links exist.
